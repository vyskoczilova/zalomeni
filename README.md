## Zalomeni

Zalomeni improves line breaks in WordPress (widely used on Czech sites).

This repo contains the maintenance work to fix a reported “unescaped input” security issue and ship an update so the plugin can be reopened on WordPress.org.

This is an attempt to fix the plugin URL for the [Zalomeni plugin page](https://wordpress.org/plugins/zalomeni/) (set by Honza Skypala).

Maintained by vyskoczilova ([WordPress profile](https://profiles.wordpress.org/vyskoczilova/#content-plugins)).
